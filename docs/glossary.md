# Glossary

| Term | Meaning in HACF |
|---|---|
| **AI system** | Any system that generates content, predictions, recommendations or decisions, or takes actions, using machine learning or similar techniques. |
| **Agent** | An AI system that plans and executes multi-step actions using tools or other systems, with some autonomy. |
| **Artefact** | A real work product (workflow, solution, decision record, document) used as evidence. |
| **Capability** | Demonstrated ability to achieve outcomes in context. Broader than knowledge or skill. |
| **Evidence level (E1–E5)** | Strength of proof behind a result. |
| **Flag** | A pattern in the profile that signals risk or opportunity (`RISK-J`, `RISK-R`, `UNTAPPED`, `CEILING`, `EVIDENCE-CAP`, `PROVISIONAL`). |
| **Gate** | Minimum dimension score required for a level. |
| **HACF Index** | Organisational metric: mean level ÷ 5 × 100. |
| **Human-in-the-loop** | A person approves each AI action before it takes effect. |
| **Human-on-the-loop** | A person monitors AI actions and can intervene or stop them. |
| **Interaction mode** | The person's relationship to AI: Observe, Ask, Collaborate, Delegate & Orchestrate, Govern. |
| **Profile** | The five dimension scores, e.g. `[K3·A4·C2·J3·R3]`. |
| **Role coverage** | Share of people meeting their role's target profile. |
| **Scope of impact** | Whose work the person's AI capability changes: Self, Team, Organisation, Ecosystem. |
| **Target profile** | Minimum dimension scores required for a role; a business decision. |
