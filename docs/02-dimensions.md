# 02 · Five Dimensions

*Layer: Core (dimension definitions) + Indicators (0–5 descriptors).*

Each dimension is scored on a 0–5 scale. Scores are independent: a person can be A4 and J2 at the same time — and that combination is exactly what an organisation needs to see.

| Score | General meaning |
|---|---|
| 0 | No evidence |
| 1 | Recognises / basic awareness |
| 2 | Applies to simple, familiar situations |
| 3 | Applies independently to complex, varied situations |
| 4 | Designs for others; anticipates problems |
| 5 | Shapes practice beyond own organisation; recognised reference |

---

## K — Knowledge
*Understanding how AI systems work, what they can do, and why they fail.*

| Score | Descriptor |
|---|---|
| 0 | Cannot describe what generative AI does. |
| 1 | Knows AI produces generated, probabilistic output that may be wrong; knows common use cases. |
| 2 | Understands context, input quality, knowledge limits, typical failure modes (fabrication, outdated knowledge, bias, instruction-following failures). |
| 3 | Understands system types (assistant, retrieval-augmented, agent, fine-tuned/specialised model), their trade-offs in cost, latency, quality and risk; reads vendor claims critically. |
| 4 | Explains evaluation, grounding, tool use, autonomy and security threats (e.g. injection, data exfiltration) well enough to design around them. |
| 5 | Contributes new knowledge: research, standards, widely used guidance. |

## A — Application
*Achieving real work outcomes with AI.*

| Score | Descriptor |
|---|---|
| 0 | Does not use AI for work. |
| 1 | Has tried AI on isolated tasks, inconsistently. |
| 2 | Uses AI regularly for own routine tasks with clear benefit. |
| 3 | Uses AI for complex, multi-step professional work; maintains repeatable workflows; measures effect. |
| 4 | Transforms how a team works with AI; outcomes are measurable at team level. |
| 5 | Achieves outcomes that change practice in the organisation or industry. |

## C — Creation
*Building reusable AI-enabled solutions.*

| Score | Descriptor |
|---|---|
| 0 | Does not create anything reusable. |
| 1 | Saves and reuses own instructions/templates. |
| 2 | Builds personal workflows chaining steps or tools; documents them for reuse. |
| 3 | Builds simple solutions used by others (shared assistants, automations) with basic testing. |
| 4 | Builds solutions integrated with data and systems, with permissions, tests, monitoring and human control points. |
| 5 | Designs platforms, reference architectures or multi-agent systems used across the organisation or beyond. |

## J — Judgment
*Verifying output, detecting errors, deciding when and how far to trust AI.*

| Score | Descriptor |
|---|---|
| 0 | Accepts AI output as given. |
| 1 | Knows output must be checked; checks occasionally. |
| 2 | Systematically verifies facts, figures and sources in own output; notices obvious errors. |
| 3 | Detects subtle errors in own domain; decides when not to use AI; calibrates trust to task risk. |
| 4 | Designs verification and oversight for others: evaluation criteria, test sets, review points, escalation. |
| 5 | Sets organisational or sector norms for evaluation and oversight of AI. |

## R — Responsibility
*Data protection, security, legal, ethical and accountability aspects of AI use.*

| Score | Descriptor |
|---|---|
| 0 | Unaware of AI-related rules or risks. |
| 1 | Knows the organisation's AI rules and which data must not be shared. |
| 2 | Consistently follows rules; chooses tools according to data classification; discloses AI use where required. |
| 3 | Recognises risks in new situations (IP, personal data, bias, labelling of synthetic content, client confidentiality) and acts correctly without a rule. |
| 4 | Designs controls: access rights, logging, risk classification, policies for a team or solution. |
| 5 | Leads AI governance at organisational level; shapes regulation or standards. |

---

## Common profile patterns

| Pattern | Example profile | Interpretation | Typical action |
|---|---|---|---|
| **Cautious expert** | K4 A2 C1 J4 R4 | Understands deeply, applies little | Hands-on workflows, quick wins |
| **Power user at risk** | K2 A4 C3 J2 R1 | Productive but unsafe | Judgment & responsibility training before scale |
| **Builder without users** | K3 A2 C4 J3 R3 | Builds, but weak link to work outcomes | Pair with process owners |
| **Balanced practitioner** | K3 A3 C2 J3 R3 | Solid L3 | Candidate for AI Champion |
| **Leader on paper** | K2 A2 C1 J2 R3 | Senior title, low capability | Executive programme; do not delegate AI strategy blindly |
